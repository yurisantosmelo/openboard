## Overview

The Web App talks to the backend over the HTTP API. It lands signed-in Users directly on their active Project Board with header switchers for Organizations and Workspaces, drag-and-drop Status transitions, a two-column Work Item creation modal, customizable workflow configuration, Eras, Links, Saved Views, Teams and Lifecycle management.

Its features communicate with [[service|IdentityModule]], [[service|OrganizationsModule]] and [[service|WorkModule]].
