## Overview

A new Project starts with `Epic`, `Feature`, `User Story`, `Task`, `Bug` and `Subtask`. Removing a Work Item Type requires a replacement Work Item Type in the same Project; incompatible Parent pairs are cleared and incompatible estimate units are discarded.
