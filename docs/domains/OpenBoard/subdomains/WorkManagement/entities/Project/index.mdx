## Overview

Creating a Project seeds its default Statuses (`Backlog`, `To Do`, `In Progress`, `Done`) and default Work Item Types (`Epic`, `Feature`, `User Story`, `Task`, `Bug`, `Subtask`) with their initial hierarchy.

A Project is read-only whenever it is Archived or its owning Workspace is Archived. Moving a Project to another Workspace in the same Organization preserves all Work Items, workflow rules, Eras and Views while removing its Project Team associations.
