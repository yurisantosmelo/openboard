properties:
  - name: project_id
    type: UUID
    required: true
    description: The associated Project.
    references: Project
    referencesIdentifier: id
    relationType: belongsTo
  - name: team_id
    type: UUID
    required: true
    description: The Team from the Project's own Workspace.
    references: Team
    referencesIdentifier: id
    relationType: belongsTo
  - name: created_at
    type: timestamp
    required: true
    description: When the Team was associated with the Project.
---

## Overview

Only Teams belonging to the Project's own Workspace can be associated with it. Moving a Project to another Workspace clears its Project Teams.
