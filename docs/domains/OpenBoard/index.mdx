## Overview

OpenBoard is organized by Domain-Driven Design subdomains. This catalog documents the subdomains that have code, and [[diagram|subdomain-map]] shows the complete classification, including what is still planned.

| Subdomain | Type | Status |
|-----------|------|--------|
| [[domain\|WorkManagement]] | Core | Implemented in part |
| [[domain\|OrganizationalStructure]] | Supporting | Implemented |
| [[domain\|Identity]] | Generic | Implemented |

[[domain|WorkManagement]] is the core domain (ADR 0010): Projects, customizable Statuses and Work Item Types, Transition Rules, Work Items, Links, Eras, Saved Views, Teams and Lifecycle (`Archived` and `Pending Deletion`). Modules remain planned.

## Architecture

The subdomains run inside [[system|OpenBoardPlatform]], a Modular Monolith with a single backend deployable.
